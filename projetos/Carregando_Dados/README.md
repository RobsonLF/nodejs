# Carregando dados

Para abrir a página e salvar contatos no arquivo `pessoas.json`, inicie o servidor na pasta deste projeto:

```bash
node server.js
```

Depois, acesse <http://127.0.0.1:3000>. Não abra o arquivo `index.html` diretamente: o formulário precisa da API local para gravar os dados.

Para escolher outra porta, defina a variável de ambiente `PORT` antes de iniciar o servidor.
