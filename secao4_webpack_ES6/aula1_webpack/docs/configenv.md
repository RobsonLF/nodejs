# Configuração para Webpack

**Passo1 -** Garantir que a pasta do node está dentro da pasta do projeto e dentro de tools

**Passo2 -** Executar arquivo ativar-node.cmd pelo terminal

**Passo3 -** No terminal execute **npm init -y** para criar o arquivo package.json

**Passo4 -** Começar a instalar dependencias

```Shell
npm install --save-dev @babel/preset-env @babel/core @babel/cli babel-loader webpack webpack-cli regenerator-runtime core-js@2
```

**Passo5 -** Criar arquivo **webpack.config.js**

**Passo6 -** Código do arquivo webpack
